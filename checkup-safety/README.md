# 검진 안전 알리미 (교육용 프로토타입)

건강검진 현장에서 **문진 + 오늘 측정값 + (있으면) 과거 기록**을 조합해, 예정된 검사에서 위험이 커지는 수검자를 실시간으로 찾아 해당 검사실에 경고와 조치를 띄우는 프로그램입니다.

> ⚠ 교육용 프로토타입입니다. 실제 진단·치료·처방 결정에 쓰지 마세요. 모든 데이터는 합성(가상) 데이터입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py          # 브라우저에서 http://localhost:8501
pytest -q                     # 규칙 엔진 테스트 (23개)
```

- API 키, 유료 서비스, 인터넷 연결이 필요 없습니다.
- **실시간 시연:** 브라우저 탭을 2개 엽니다. 한쪽은 [실시간 대시보드], 다른 쪽은 [② 신체계측]에서 혈압을 입력하면 대시보드에 3초 안에 경고가 나타납니다.
- **빠른 시연:** 왼쪽 [시연 시나리오 8건 한꺼번에 등록] 버튼을 누릅니다.

## 구조

```
app.py               Streamlit 화면 (대시보드 / 접수·문진 / 신체계측 / 검사실 / 규칙 / 코호트 검증)
engine.py            규칙 평가 엔진 (BMI·STOP-Bang 계산, 조건 평가, 중복 경고 정리)
rules.yaml           위험 규칙 34개 + 참고문헌  ← 기준값은 여기만 고치면 됨
synthea_loader.py    Synthea 합성 EMR → 병력·약물·최근 검사값 자동 입력
prepare_synthea.py   Synthea 원본 CSV를 앱용 작은 파일로 정리
demo_cases.yaml      시연 시나리오 8건 (테스트의 기대값 포함)
tests/test_engine.py 규칙 파일 점검, 시나리오, 경계값, 결측 처리 테스트
data/synthea/        합성 성인 환자 86명 (seed 42)
```

데이터 흐름:

```
접수(문진 + 선택적으로 Synthea EMR) ─┐
신체계측(키·체중·혈압·혈당·SpO₂) ───┼─▶ engine.assess(상태, 오늘 검사) ─▶ 규칙 발동
(검사 예정 목록) ─────────────────────┘                                   │
                                                   검사실별 경고 + 조치 + 근거 문헌 ◀┘
```

## 규칙 모듈

| 모듈 | 예시 규칙 |
|---|---|
| A 채혈 실신·출혈 | 과거 채혈 실신 + (SBP<100, BMI<18.5, 탈수, 금식 ≥12h) → 앙와위 채혈 |
| B 금식 저혈당 | 당뇨 + 인슐린/설포닐우레아 + 금식 검사 → 접수 즉시 혈당 측정 |
| C 조영제 | 조영 CT + eGFR<30 또는 AKI → 영상의학과 보고 |
| D MRI 안전 | 삽입 기기 + MRI → MR Conditional 확인 전 진행 금지 |
| E 임신 | 가임기 여성 + 방사선 검사 + 임신 여부 미확인 → 확인 |
| F 낙상 | 65세 이상 + 낙상력/보행보조기구 → 동행·보조 |
| G 진정 내시경 | STOP-Bang ≥5 / BMI ≥35 / OSA → 진정 담당의 보고 |
| H 운동부하·폐기능 | 심질환·운동 시 흉통 → 검사 전 의사 평가 |
| I 공통 | SpO₂<90, 발열, 인지장애 |

각 규칙에는 근거 수준이 붙어 있습니다: `guideline`(지침 기준), `adapted`(지침을 검진 상황에 맞게 조합), `team`(팀 설정, 지도교수 검토 필요).

## Synthea 데이터 다시 만들기

```bash
java -jar synthea-with-dependencies.jar -p 120 -s 42 --exporter.csv.export true \
     --exporter.fhir.export false --exporter.baseDirectory ./out Massachusetts
python prepare_synthea.py ./out/csv
```

## 알려진 한계

- 기준값은 학생 팀이 문헌을 정리한 것으로, 임상 전문가 검증을 거치지 않았습니다.
- 실제 사건(실신·저혈당 발생) 데이터가 없어 민감도·특이도는 측정할 수 없습니다. 현재 검증은 시나리오 테스트와 합성 코호트에서의 경고 빈도 분석까지입니다.
- Synthea는 미국 인구 기반이며 실신 경험·조영제 반응·임신 가능성 같은 문진 항목은 만들지 않습니다.
- 저장소는 서버 메모리입니다(DB 없음). 서버를 다시 켜면 대기열이 사라집니다.
- 경고가 너무 많으면 직원이 무시하게 됩니다(alert fatigue). 합성 코호트 검증 화면에서 규칙별 발동 빈도를 확인할 수 있습니다.
